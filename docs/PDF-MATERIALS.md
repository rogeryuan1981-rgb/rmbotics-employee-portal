# PDF 教材上傳

教材庫支援直接上傳 PDF，保留外部 HTTPS PDF 檔案網址。OneDrive 與 SharePoint 的分享頁面網址不等於 PDF 檔案網址，平台會指出問題並提示改用上傳。

## 套用步驟

1. 套用 `20261116094447_training_material_storage.sql` migration，初始化私人教材儲存空間及權限。正式部署流程會自動完成。
2. 部署本次前端程式。
3. 後台開啟「教材庫」，新增或編輯教材，選擇 PDF，再從電腦選擇檔案。完成上傳後按「儲存教材」。單份上限 20 MB。
4. 將教材加入課程，發布內容。若替換的是已指派課程的教材，依現有課程同步功能將更新套用至既有要求。
5. 以實際被指派的員工帳號確認 PDF 能正常載入及翻頁，載入成功後才能計入學習時間。

## 權限與版本

檔案存放在私人 `training-materials` bucket，不使用公開網址或到期下載網址。管理員可以上傳及讀取，員工需有教育訓練使用資格及對應的有效課程指派，且檔案已出現在該課程發布內容中，才能讀取。被取消指派、未指派、已停用或工作階段失效的帳號不能讀取。

每次上傳產生獨立檔案路徑，禁止覆寫及刪除已上傳檔案，以保留既有發布內容。尚未儲存教材而取消操作的上傳檔案仍僅管理員可讀，不會直接開放給員工。

為避免 PostgreSQL 在檢查其他 bucket 時被證書 policy 的私人資料表查詢阻擋，migration 會將既有外訓證書判斷移入授權函式。有效權限範圍不變：本人仍可上傳及查看，原有部門管理範圍仍可審核查看。

## 驗證

`npm run test:pdf` 驗證 PDF 格式、檔案大小、分享網址辨識及資料庫實際 RLS 權限。`npm run build` 檢查型別及正式建置。上述自動測試不等同已驗證正式環境的 Storage HTTP 上傳及瀏覽器閱讀流程，部署後仍須完成上述第 5 步。
