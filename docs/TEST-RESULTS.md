## 瀏覽器實際操作

1. 本機郵件匣取得亂數 Email 驗證碼登入；同一登入切換教育訓練及零食投票，新分頁免重驗證，任一分頁登出同步失效。
2. 共用電腦新分頁單一登入；確認 token 沒有寫入 localStorage。
3. 管理員建立課程、文字教材、題目並發布；指派員工；下載真正的 XLSX，重新解析檔案確認資料列及原期限欄位。
4. 學員在時數不足時不能開始測驗；等待真實心跳計時後開放；選擇答案、保存、交卷及格，重新整理後仍可查回完成紀錄。
5. 390×844 手機檢視入口沒有水平溢出；學員看不到訓練後台入口，直接輸入後台網址也沒有管理資料。
6. PDF.js 實際載入及繪製本機控制的 PDF 測試檔；404 教材顯示錯誤，計時保持暫停及零累計。此項使用瀏覽器網路攔截提供測試 PDF，未冒稱已驗證任意外部 PDF 來源。
7. 將共用最後有效活動時間設為 31 分鐘前以模擬閒置；切換模組不重設，系統於檢查時登出。未為此實際等待 31 分鐘。
8. HR 在畫面選取真正 XLSX：有一列錯誤時不可提交；更正後兩列整批匯入。新員工可在本機完成首次驗證碼登入，但沒有被自動開通訓練或零食資格。

## 尚未驗證與執行限制

- 未取得遠端 Supabase URL／publishable key／service role 的測試設定，未在真正 Supabase Auth、PostgREST、Storage、Realtime 或正式資料上執行。Email OTP 單一登入已驗證本機流程，真正 Supabase 寄信與新裝置撤銷仍需在測試專案確認，包含建立 Auth session 觸發器的管理權限。
- 未設定 SMTP 或 Resend API key，未向任何真實員工寄信；未驗證真實信箱可達性、退信或供應商端接受後斷線等情境。去重及超過重試時窗轉人工核對的程式已實作。
- 未以實際公司 YouTube 教材進行播放測試。播放器已按官方 IFrame API 實作；前景／播放／暫停／緩衝規則已有後端狀態測試，但仍須確認實際影片允許內嵌且未被網路政策阻擋。
- PDF 已以受控檔案驗證實際繪製；任意外部 PDF 網址仍須確認 HTTPS 與 CORS。未提供職務說明書檔案匯入。
- 沒有對真實多人同時登入進行負載測試。交易鎖、唯一索引及重送行為已有本機測試；PGlite 的執行環境不能取代正式 PostgreSQL 多連線競爭驗證。
- 手機使用桌面瀏覽器的 390×844 檢視驗證；未執行實體 iOS／Android 測試。
- 建置仍有大型 chunk 提示，主要來自原有零食介面、PDF.js 及 ExcelJS；不影響本次建置及功能驗證。尚未量測真實行動網路效能。
